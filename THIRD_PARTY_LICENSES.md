# Third-party data & licenses

This fan wiki is unofficial and not affiliated with Pawprint Studio or FunPlus.
The interactive map uses open map data and an open-source map library, listed below
with the attribution each license requires.

## Map base image

The interactive map uses an **original fan-made illustration** of the Idyll (에이델)
continent created for this project (`public/art/idyll-map.jpg`). It is not the official
Aniimo map and its coordinates are not official. No open-licensed Aniimo world map exists;
community interactive maps use the publisher's copyrighted assets and are not reused here.

## Libraries

- **Leaflet** (map engine) — BSD-2-Clause. https://leafletjs.com
- **Next.js** — MIT. **React** — MIT. **Tailwind CSS** — MIT.
- Fonts: **Noto Sans KR** and **Jua** via Google Fonts (SIL Open Font License 1.1),
  self-hosted by `next/font`.

## Illustrations

The creature and scenery illustrations under `public/art/` are original fan-made
artwork created for this project for mood/decoration only. They are not official
Aniimo assets. Official creature art can be viewed via the per-creature "source"
links to the official index (`wiki.aniimo.com`).

## Creature data

Korean creature names come from the official Aniimo index (`wiki.aniimo.com/ko`),
matched to English names via the shared official image asset id. Names are stored as
factual data with per-entry source links; no official images are copied or rehosted.
